# Anoop Kumar Dubey — Personal Portfolio

A premium dark-themed personal portfolio website built with vanilla HTML, CSS, and JavaScript. No frameworks. No dependencies.

## Live

[anoopdubey.gt.tc](https://anoopdubey.gt.tc)

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Fully responsive (mobile, tablet, desktop)
- Scroll-reveal animations
- Typewriter role switcher
- Cursor orb ambient effect
- Smooth scrolling navigation
- Project showcase with GitHub & live links
- Contact section with social links

## Structure

```
portfolio/
├── index.html
├── style.css
├── script.js
├── profile1.jpg
└── README.md
```

## Setup

Clone the repo and place your `profile1.jpg` in the root folder. Open `index.html` in any browser — no build step required.

```bash
git clone https://github.com/Anoopkumard12220/CodeAlpha_Portfolio.git
cd portfolio
```
